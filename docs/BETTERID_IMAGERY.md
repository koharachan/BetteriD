# 卫星影像裁切、标注再导入

用当前底图裁一块图，在外面描线，再导回 BetteriD，生成可检查的 OSM 几何。

## 导出

1. 把地图缩放到要画的范围，并选中已有要素（不选中就导出整个可见画面）。
2. 在左侧工具条的 **文件与编辑** 里点 **导出影像裁切**。
3. 浏览器下载 `betterid-imagery.png`。

PNG 里有一块 `betterid-georef` 文字信息，记录裁切范围和当时的 Web Mercator 变换。同一份 JSON 也会记在本机偏好里，给丢掉文字块的软件留退路。

## 标注

在 Photoshop、其他画图软件，或让图像模型在**同一张图**上描：

- **红色闭合线**：建筑，导入后是 `building=yes`
- **绿色闭合线或绿色填充**：区域，导入后是 `area=yes`

线要细、要闭合。不要裁掉画面、不要改比例。可以整体缩放，导入时会按宽高比例把像素对回导出时的坐标。旋转、透视或局部变形对不回去。

## 导入

点 **导入标注影像**，或把 PNG 拖到地图上。BetteriD 读出坐标，把红线和绿线变成闭合的线，并选中它们。这是一步可撤销的本地编辑，上传前要对照底图检查。

没有坐标信息、也没有同一次导出留下的记录时，导入会停下来，不会猜位置。
